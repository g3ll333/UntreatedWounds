# UntreatedWounds

A safe space for unseen wounds. Read the hidden pains of others, or leave your own memory behind, and let it heal.


**About the Project**

Untreated Wounds is an interactive, minimalistic web archive designed to collect and display anonymous emotional memories. Conceived as a metaphorical healing space, it allows users to share a painful experience and cover it with a digital plaster.

By visiting the archive, users are presented with a clinical, airy canvas filled with various plasters. By gently dragging the plasters away, the hidden, unhealed wounds of other people are temporarily revealed.

This project was created with a minimalist, clean, and empathetic design, reflecting the identity of Dr. Ausbüttel.


**Features**

Interactive Canvas: Fluid, hardware-accelerated drag-and-drop mechanics to move the plasters and read the hidden text.

Anonymous Submissions: Users can entrust their memories to the archive using a simple, distraction-free form.

Dynamic Plasters: Different shapes and sizes of plasters (round, square, normal, double) that adapt to the text.

Smart Layout Engine: A zero-tolerance mathematical algorithm ensures that memories and plasters are organically scattered across the screen without ever overlapping or getting cut off by the screen borders.

Google Sheets Integration: The backend is powered by a seamless Google Apps Script integration, allowing the archive to grow dynamically as new memories are submitted.


**How it works**

Explore: Drag the plasters on the screen to read the hidden stories. The plasters will gently fade out and return to their original position after a few seconds.

Share: Refresh the page to access the submission form, choose the plaster that best fits your wound, and leave your memory.


**Setup**

The project is built using standard HTML, CSS, and vanilla JavaScript. No complex build tools are required.
To run the project locally, simply clone the repository and open index.html in any modern web browser.
